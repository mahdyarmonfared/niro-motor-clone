# 🏍️ پروژه بازطراحی و کلون وب‌سایت گروه صنعتی نیرو موتور (Niro Motor Group)

یک کلون پیشرفته، تعاملی، واکنش‌گرا (Responsive) و مدرن از وب‌سایت رسمی **گروه صنعتی نیرو موتور** ([niroomotorgroup.com](https://niroomotorgroup.com/))؛ بزرگترین تولیدکننده موتورسیکلت در ایران (یاماها، تی‌وی‌اس، گلکسی، احسان و پرواز).

---

## ✨ امکانات و ویژگی‌های پیاده‌سازی شده

### ۱. امکانات وب‌سایت اصلی (Official Features)
- **مگامنوی هوشمند در هدر:** دسته‌بندی تفکیک‌شده بر اساس کلاس موتورسیکلت (اسکوتر شهری، استریت اسپرت، تریل آفرود، ادونچر مسافرتی) و برندهای معتبر (یاماها، تی‌وی‌اس، گلکسی SYM و نیرو موتور).
- **موتور جستجوی بلادرنگ (Live Search):** جستجوی سریع با شورتکات کیبورد `Ctrl+K` روی مدل‌ها، برندها، مشخصات و حجم سیلندر همراه با پیش‌نمایش آنی نتایج.
- **اسلایدر محصولات پرفروش:** اسلایدر لمسی و کلیکی برای محصولات برتر با دکمه‌های کنترل و سوایپ.
- **فیلتر و مرتب‌سازی چندگانه کاتالوگ:**
  - فیلتر بر اساس برند سازنده
  - فیلتر بر اساس کلاس و کاربری موتورسیکلت
  - فیلتر وضعیت موجودی انبار
  - مرتب‌سازی بر اساس: ارزان‌ترین، گران‌ترین، جدیدترین و بیشترین حجم سیلندر
- **مودال نمایش شناسنامه و مشخصات فنی کامل (Quick View Modal):** نمایش تمامی جزئیات فنی موتورسیکلت شامل حجم موتور، توان خروجی، سیستم سوخت‌رسانی EFI، ترمزهای ABS، ظرفیت باک و حداکثر سرعت.
- **راهنمای جامع سئو و خرید (SEO Expandable Guide):** محتوای تحلیلی برای انتخاب کلاس‌های مختلف موتور با انیمیشن روان باز و بسته شدن.
- **مودال‌های اختصاصی خدمات مشتریان:**
  - 📍 **لیست شعب و نمایندگی‌ها (Branch Locator):** تفکیک استانی شعب تهران، اصفهان، شیراز، مشهد و تبریز به همراه آدرس و تماس مستقیم.
  - 🚨 **امداد موتور ۲۴ ساعته:** سامانه تماس فوری و اعزام امدادگر سیار با شماره ۰۲۱-۴۷۷۶۲.
  - 🛡️ **استعلام گارانتی و پیگیری سفارش:** با شماره شاسی موتور (VIN) یا شماره همراه.
  - 📅 **رزرو آنلاین نوبت خدمات:** فرم رزرو سرویس دوره‌ای در نمایندگی‌های رسمی.

### ۲. فیچرهای مدرن و ارزش‌آفرین پیشنهادی (New Modern Features)
- 🧮 **محاسبه‌گر هوشمند اقساط (Installment Calculator):**
  - انتخاب مدل موتورسیکلت
  - تعیین درصد پیش‌پرداخت (اسلایدر و دکمه‌های ۳۰٪، ۴۰٪، ۵۰٪، ۶۰٪)
  - انتخاب دوره بازپرداخت (۶، ۱۲، ۱۸، ۲۴ ماهه)
  - محاسبه دقیق اقساط ماهیانه، سود و صدور پیش‌فاکتور محاسباتی.
- ⚖️ **سیستم مقایسه رو در رو موتورسیکلت‌ها (Comparison Tool):** انتخاب همزمان تا ۳ مدل و مقایسه مشخصات در جدول فنی همراه با نشانگر تعداد در هدر.
- ❤️ **لیست علاقه‌مندی‌ها (Wishlist):** نشان‌دار کردن موتورها با ذخیره در `localStorage` و مودال مدیریت علاقه‌مندی‌ها.
- 🌓 **حالت تاریک و روشن (Dark / Light Mode):** تغییر تم با انیمیشن نرم و حفظ ترجیح کاربر.
- 📱 **منوی کشویی موبایل (Off-canvas Drawer):** منوی اختصاصی برای کاربران موبایل و تبلت با آکاردئون دسته‌بندی‌ها و لینک‌های سریع.
- 🔑 **سیستم احراز هویت بومی با کد پیامکی (OTP Auth):**
  - ورود با شماره موبایل ایران (`09xxxxxxxxx`)
  - تایمر معکوس ۱۲۰ ثانیه‌ای برای ارسال مجدد کد
  - ذخیره نشست در LocalStorage و نمایش نام کاربر و منوی پروفایل در هدر.

## 🛠️ تکنولوژی‌های استفاده‌شده (Tech Stack)

- **HTML5:** ساختار معنایی، استاندارد و سئو محور (Semantic HTML)
- **SCSS (Sass):** معماری ماژولار، متغیرها، گرید و فلکس‌باکس، انیمیشن‌ها و پشتیبانی تم دارک
- **JavaScript (Vanilla ES6+):** عملکرد بلادرنگ بدون وابستگی به فریم‌ورک‌های سنگین
- **Boxicons:** آیکون‌های وکتور زیبا و سبک
- **IRANYekan WebFont:** تایپوگرافی اصیل و خوانا

## 🚀 نحوه اجرا (Getting Started)

1. مخزن را کلون کنید:
```bash
git clone https://github.com/YOUR_USERNAME/niro-motor-clone.git
cd niro-motor-clone
```

2. فایل `index.html` را در مرورگر یا با افزونه **Live Server** در VS Code باز کنید.

3. در صورت اعمال تغییرات در استایل‌های SCSS، برای کامپایل مجدد از دستور زیر استفاده نمایید:
```bash
npx sass scss/main.scss scss/main.css
```

## 📁 ساختار پوشه‌بندی (Project Structure)

```text
├── assets/
│   └── img/                 # تصاویر موتورسیکلت‌ها، اسلایدرها و لوگوها

├── login.html               # صفحه ورود و عضویت
├── .gitignore
└── README.md
```
